## 🚀 Quick Start

### 1. Firebase Setup
```bash
npm install -g firebase-tools
firebase login
firebase init
```

### 2. GitHub Setup
```bash
# Clone repos
git clone https://github.com/msitarzewski/agency-agents.git
git clone YOUR_PEPPERCLAW_REPO
```

### 3. Deploy to Firebase
```bash
cd pepperclaw
firebase deploy --only hosting
```
